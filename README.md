# Cash Out - Auto Scan

Auto-scan version of the cash out sheet app. Processes all POS receipt photos in sequence without requiring manual "Confirm & Next" between each scan.

## Usage

1. Open https://abhinavmanocha.github.io/cash-out-auto-scan/
2. Tap the **Key** button to enter your Gemini API key
3. Take photos of your POS reports
4. Hit **Scan All Photos** — they auto-process one by one
